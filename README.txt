EBENSYSTEM V3
=============

Site institucional da Ebensystem Tecnologia LTDA.

Estrutura:
- index.html       -> página inicial
- servicos.html    -> serviços
- clientes.html    -> modelo de atuação / terceirização técnica
- historia.html    -> apresentação da empresa
- contato.html     -> formulário de contato
- app.js           -> menu responsivo
- css/style.css    -> identidade visual e responsividade
- img/logo.png     -> logotipo

O site mantém o endpoint do formulário Google Apps Script presente na versão recebida.
Antes de publicar em produção, confirme que esse endpoint continua ativo e autorizado a receber as mensagens.
